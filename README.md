# ARA Viewer

Pemutar panorama 360° untuk klien desainer yang memakai ARA.

**Buka:** https://gigihwicaksono09-spec.github.io/ara-viewer/

1. Di WhatsApp, tekan berkas panorama dari desainer Anda → Bagikan → Simpan ke File.
2. Buka alamat di atas, tekan **Pilih berkas**, lalu pilih berkas tadi.
3. Geser layar, atau putar HP, untuk melihat sekeliling.

Dibutuhkan terutama di iPhone: pratinjau berkas di WhatsApp/Files tidak bisa memutar panorama.
Di Android dan komputer, berkas dari ARA bisa langsung dibuka dengan Chrome.

## Privasi

Berkas hanya dibuka di HP Anda dan **tidak diunggah ke mana pun**. Halaman ini memasang aturan
keamanan browser (Content-Security-Policy `default-src 'none'`) sehingga ia memang tidak bisa
mengirim data ke internet. Halaman ini hanya satu berkas `index.html`, tanpa pelacak dan tanpa
skrip dari pihak lain.
